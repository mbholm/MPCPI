# Replication package for *Monetary Transmission to Prices: Disaggregated Evidence from Norway*

Martin B. Holm (University of Oslo) and Simon Seland (University of Oslo).
Corresponding author: m.b.holm@econ.uio.no.

Please cite the paper when using this package: Holm, M. B. and S. Seland (2026),
"Monetary Transmission to Prices: Disaggregated Evidence from Norway", working paper,
University of Oslo. This line will be updated with the journal reference once the paper
is published.

This package reproduces every figure and every statistic quoted in the paper and its online
appendix, starting from raw data. It is self-contained: all inputs are included, except that
the public data can optionally be re-downloaded from the Statistics Norway and Norges Bank APIs.

```
  R (fetch data, build panels)      Stata (local projections)        MATLAB (figures)
  code/data_prep/*.R          ->    code/stata/*.do            ->    code/matlab/plot_figures.m
        |                                 |                                 |
  inputs/*, data/*.dta               output/coeffs_*.xlsx              figures/figure*.eps
```

The pipeline takes roughly 45 minutes on a laptop, almost all of it in Stata (about 20,000
local-projection regressions).

## 3. How to run

### Quick start

```bash
# macOS / Linux                              # Windows PowerShell
./run_all.sh                                 ./run_all.ps1
REPL_USE_FALLBACK=1 ./run_all.sh             $env:REPL_USE_FALLBACK=1; ./run_all.ps1     # offline, see below
```

Edit `STATA_BIN` / `MATLAB_BIN` (or pass `-StataBin` / `-MatlabBin`) if the executables have
other names on your system. On Windows, Stata's batch mode opens a Stata window while it runs;
if you prefer, run the Stata stage from an interactive session as described next.

### Stage by stage

1. **R** (data and panels). From the package root:
   ```bash
   Rscript run_all.R
   ```
   Downloads the public series (skipped with `REPL_USE_FALLBACK=1`), derives the import shares
   from the WIOD table, and writes `data/estimation_dataset.dta` (3-digit COICOP panel) and
   `data/estimation_dataset_main_categories.dta` (16 main categories).

2. **Stata** (regressions). Start Stata with the working directory set to the package root, then
   ```stata
   do code/stata/run_all.do
   ```
   Writes `output/coeffs_*.xlsx` (one file per impulse response: columns are the point estimate,
   standard error and number of observations, one row per horizon), `output/first_stage.log`,
   `output/exposure_measures_by_index.xlsx` and `output/placebo_govreg_ids.txt`.

3. **MATLAB** (figures). From any working directory:
   ```bash
   matlab -batch "run('<path to package>/code/matlab/plot_figures.m')"
   ```
   Writes all figures to `figures/`.

### Offline mode and data vintage

`REPL_USE_FALLBACK=1` makes the R stage skip the API downloads and use the files shipped in
`inputs/` and `data/`. **Use this mode to reproduce the paper exactly.** The live Statistics
Norway and Norges Bank series are a later vintage than the shipped files (CPI rebasing and
national-accounts revisions), so a fresh download reproduces the results closely but not
value-for-value. The fetch scripts check the shape of what they download and stop with a clear
message if a table has been renamed or restructured.

### Firm statistics (restricted microdata)

The firm-level accounts statistics of Statistics Norway are confidential and can only be
accessed on its microdata server. `code/server/firm_statistics_server.do` is the script we ran
there. For each 2-digit NACE sector it sums, over all non-financial firms and over the years
2008–2019: total operating costs; long-term debt net of debt to companies in the same corporate
group; total assets; current assets and current liabilities; labour costs, material costs and
revenue; interest costs (external interest only); and the operating result. The sums (scaled by
10^12 NOK) are what `inputs/firm_statistics.csv` contains, so the paper can be reproduced
without server access. `prep_data.R` maps the numeric NACE codes to the labels of the bridge
matrix and bridges the sums to COICOP; the exposure measures used in the paper (debt-to-cost
ratio, net working capital to sales, interest expenses to costs, interest coverage ratio) are
ratios of these COICOP-level sums and are formed in `micro_regressions.do`. The resulting values
by index are in `output/exposure_measures_by_index.xlsx`.

### Derived files

`inputs/cpa_import_share.xlsx` (import content of consumption by CPA sector, from
`derive_import_shares.R`), all `data/*.dta` (from the R prep scripts and the Stata macro
scripts), and `data/mp_shocks.csv` (the monthly shock series written by
`macro_monthly_regressions.do` and read by MATLAB for Figure 1; shipped so that the figure
stage can be run on the included `output/coeffs_*.xlsx` without rerunning Stata).

## 6. Notes on the implementation

- **Specification.** All responses are instrumental variable local projections (equations 1–2
  of the paper; 3–5 for the interactions), horizon 0–60 months (0–20 quarters for the labour
  market), with 36 lags of the policy-rate change, 11 lags of the own price change and month
  fixed effects. Newey–West standard errors for time series (`newey2`), Driscoll–Kraay for the
  panel (`xtivreg2 ... dkraay`), regressions weighted by average CPI expenditure shares.
- **Samples.** 3-digit panel: January 2001 to December 2018, 28 indices after dropping the seven
  government-regulated indices and four with incomplete coverage (082, 096, 126, 127). Aggregate
  and quarterly series: 1995–2018. The aggregate monthly regressions keep 1995–2018 as the sample
  of shocks but use CPI observations after 2018 for the leads at long horizons; the panel does not
  (its CPI data end in 2018).
- **Confidence bands.** 95 and 68 percent, using the t distribution with N − 23 degrees of freedom
  (`k_lp = 22` in `plot_figures.m`).
- **Alphabetical ids.** `id` in the Stata scripts is `egen group(price_index)`, i.e. alphabetical.
  In the 28-index sample, ids 7 and 8 are the two housing-rental series excluded in the
  "excl. housing" specifications. A change in a category label shifts the ids.
- **Placebo.** 081 Postal services is excluded from the placebo because the series is only
  available from July 2008. For series with too little price variation to include own-price lags,
  the code falls back to a specification without them and records this in `placebo_govreg_ids.txt`
  (third column); this did not occur for the five series used.
- **Paths.** Stata scripts use paths relative to the package root with forward slashes and run on
  Windows, macOS and Linux. The R scripts locate the root through the `.repl_root` marker, so they
  can be run from `code/data_prep/` as well.
